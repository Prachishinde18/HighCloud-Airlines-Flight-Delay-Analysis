# HighCloud Airlines – Flight Delay Analysis

## Project Overview
This project analyzes airline flight data to understand flight delays, cancellations, and the major causes of delays. Data analysis and visualizations are used to identify useful patterns and trends.

## Project Objectives
- Analyze total flights and cancelled flights.
- Study flight delays by month and day of the week.
- Compare airline cancellation rates.
- Analyze the major causes of flight delays.
- Present insights using dashboards and visualizations.

## Tools and Technologies
- Python
- Pandas
- Matplotlib
- MySQL
- Microsoft Excel
- Power BI
- Kaggle
- GitHub

## Project Workflow
1. Cleaned and prepared the flight dataset.
2. Used SQL queries to analyze flight data.
3. Created summaries and dashboards in Excel and Power BI.
4. Performed further analysis and created visualizations in Python.
5. Documented the project files and results.

## Project Files
- Python notebook: Flight delay analysis and visualizations.
- SQL file: Data analysis queries.
- Excel file: Excel analysis and dashboard.
- Power BI file: Interactive dashboard.
- Dashboard screenshots: Visual results of the project.

## Key Analysis Areas
- Flight volume and cancellation rate
- Monthly flight delays
- Weekday versus weekend flights
- Airline-wise cancellations
- Delay causes
- Departure and arrival delays
